# Introduction

Gildsmith merchant documentation explains how store teams use a Gildsmith-powered
commerce platform. It focuses on functional concepts, operational workflows, and
shared terminology for employees and merchants.

## Who this is for

- Store managers responsible for catalog and merchandising workflows.
- Employees who maintain product data and store content.
- Operations teams that need a functional overview of Gildsmith concepts.

## What this covers

These docs describe what store teams can do with Gildsmith. Developer-focused
implementation details live in the developer documentation site.
