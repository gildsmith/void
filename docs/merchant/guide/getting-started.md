# Getting Started

Start with the core concepts your team will use when operating a Gildsmith store.

## Learn the catalog model

Products describe sellable items. Attributes and attribute values describe the
properties that make products searchable, filterable, and understandable to
customers.

## Organize products

Product collections group products for merchandising, navigation, campaigns, and
other store experiences.

## Coordinate with developers

When a workflow requires new functionality or integration work, use the developer
documentation as the technical reference for implementation teams.
